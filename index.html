PROJECT 01 · AI/ML + FULL STACK

ScriptCare — AI Prescription Analyser

Situation / Problem

Medication dispensation errors caused by illegible handwritten doctor prescriptions in clinical workflows.

Task

Build an automated end-to-end multi-stage AI pipeline to detect, recognize, extract, and cross-validate handwritten prescriptions.

Action & Architecture

Engineered a 5-stage pipeline: YOLOv8-Nano bounding box region detection, TrOCR optical character recognition, BioClinicalBERT NER medication entity extraction, and fuzzy matching against a 280K drug database via FastAPI REST API.

Result

Achieved 91% drug entity extraction accuracy with 0.87 F1 score. Research paper submitted to ICSCSD 2026.

YOLOv8 TrOCR BioClinicalBERT FastAPI React
scriptcare_pipeline.py
# Stage 1: YOLOv8 Bounding Detection bbox = detector.detect_regions(prescription_img) # Stage 2 & 3: TrOCR + BioClinicalBERT raw_text = trocr.recognize(bbox) entities = bert_ner.extract_meds(raw_text) # Stage 4: 280K Drug DB Validation validated = drug_db.validate(entities) print("Accuracy: 91% | F1: 0.87")
